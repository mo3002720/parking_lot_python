# parking_lot_python
Parking Lot design : Garage containing multiple levels and various parking spots

The Code is written in multiple files to achieve Object Oriented Programming

ALGORITHM
1)Check if the vehicle is already parked
2)check number of spots needed
3)loop through levels to check for free spots
4)verify the vehicle fits
5)if yes, mark spot as taken and generate ticket
6)if not found then raise an error
